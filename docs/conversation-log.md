## 5. v2 디자인 시안 (무한상사풍) — 오너 반려

오너 피드백: "가을 느낌은 좋은데 안 웃기게 촌스럽다. 무한상사 느낌 폰트·디자인으로 가능할까?"
참고 이미지: 실물 검은 결재판("결재를 바랍니다"), 관공서 공문서 양식, 무한상사 폰트 검색 결과.

v2에서 만든 것 (`design-v2` 브랜치):
- 결재판: 검은 인조가죽 표지, 은색 두 줄 사이 "결재를 바랍니다", 하단 명패 창, 안쪽 검은 판 + 투명 모서리 포켓
- 공문: 표어 → "고충토로추진위원회"(넓은 자간) → 수신/(경유)/제목 → 1. 2. / 가.~마. → 붙임 … 끝. → 발신명의 + 사각 직인 → 기안자·검토자·결재권자 서명 도장 → 시행·주소·공개구분
- 페이지: 가상 회사 "고충상사" 사내 인트라넷 헤더, 노란 속보 띠, 남색 사무실(블라인드+가을 햇살) Hero, 예능 자막(Black Han Sans / Jua), 사원증 카드, 품의 파일 카드("검토중" 도장), 서식형 회신서("결재 상신")
- 실제 무한상사 로고·상표는 공개 페이지라서 쓰지 않고 분위기만 참고

**오너 결론: v2도 마음에 들지 않아 디자인을 다시 할 예정.**
